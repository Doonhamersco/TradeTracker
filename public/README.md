# Public Assets

Place your background image for the Share PNL feature here.

## Required Image

- **File name**: `jupiter-bg.png`
- **Recommended dimensions**: 800x1000px (4:5 aspect ratio)
- **Format**: PNG with transparency (optional)

The image should be the Jupiter-style background without:
- Jupiter logo (top left)
- "Jupiter" text (top right)
- "jup.ag/terminal" URL (bottom left)

The SharePNL component will overlay the trade information (coin name, profit, etc.) on top of this background image.
